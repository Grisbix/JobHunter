Depose ici ton CV (.docx de preference, sinon .pdf), un seul fichier.
Puis double-clique sur start.bat, dans le dossier launchers.
Ce dossier est ignore par git : ton CV ne sera jamais publie.

English: put your CV here (.docx preferably, otherwise .pdf), a single file.
Then double-click start.bat in the launchers folder (or run ./launchers/start.sh).
This folder is ignored by git: your CV will never be published.
